# Последний гараж

Короткометражный интерактивный survival-horror фильм о первых минутах зомби-апокалипсиса.

## Запуск
Откройте GitHub Pages или запустите локальный статический сервер. Проект не использует сборщик, внешние библиотеки, изображения или аудиофайлы.

## Структура
- `index.html` — экран фильма и элементы управления
- `style.css` — адаптивный вертикальный интерфейс 9:16
- `game.js` — таймлайн, главы, субтитры и управление воспроизведением
- `graphics.js` — Canvas-сцены, персонажи, эффекты и цветокоррекция
- `audio.js` — процедурные звуковые эффекты через Web Audio API

## Управление
- Старт / пауза
- Перезапуск
- Включение звука
- Пропуск вперёд
- Полноэкранный режим (если поддерживается браузером)

Звук запускается только после пользовательского нажатия — это ограничение браузеров, особенно на iOS Safari.
