# Последний гараж — HTML CGI prototype

Откройте GitHub Pages по адресу `https://kastew2005.github.io/Last-Garage/cgi/` после включения Pages для репозитория.

Для Three.js требуется интернет-соединение: библиотека загружается с jsDelivr CDN.

## Управление
- Play — запуск фильма и аудио.
- Pause — пауза/продолжение.
- Restart — перезапуск.
- Ползунок — перемотка по абсолютному времени.
- ♫ — звук/без звука.
- ⛶ — полный экран.

Это процедурная браузерная CGI-заготовка: модели и окружение создаются геометрией Three.js, анимация привязана к абсолютному таймлайну 0–90 секунд. Для настоящего фотореализма потребуются профессиональные внешние модели персонажей, риггинг, текстуры и отдельные звуковые записи.
